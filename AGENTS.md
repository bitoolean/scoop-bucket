# Repository guidance

- Read `.project-memory/STATUS.md` for current repository context.
- Consult `.project-memory/DECISIONS.md` before changing established conventions, and record meaningful new decisions there.
- Use `.project-memory/TODO.md` for planned work and `.project-memory/manifest.template.json` when authoring manifests.
- Keep unapproved manifest proposals in `.project-memory/drafts/` until they are approved for `bucket/`.
