# Project Memory

This is the repository's lightweight project memory: a durable, tracked record
of its purpose, active work, decisions, and drafts. It is for maintainers and
future coding sessions, not for Scoop consumers.

Read `STATUS.md` first. Record meaningful decisions in `DECISIONS.md`, track
action items and suggestions in `TODO.md`, and keep unpublished manifest proposals
in `drafts/` until they are approved for `bucket/`.
